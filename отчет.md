# Отчёт по практической №1

## 1. Вариант и масштаб

| Поле | Значение |
|---|---|
| ФИО (как в VK Education) | Мелихов Артем |
| Вариант (запрос) | Q16 (Parts/Supplier Relationship) |
| Масштаб `sfN` | sf5 |
| Почему выбрал такой масштаб | sf5 — компромисс между скоростью и объёмом: около 4 млн строк в partsupp, все тесты и бенчмарк проходят за минуты, но данных уже достаточно, то есть не слишком много и не слишком мало, видна работа агрегаций и джойнов. |

## 2. Поднятые сервисы — и почему именно они

| Сервис | Роль в стеке | Почему именно он |
|---|---|---|
| MinIO (форк coollabsio) | S3-совместимое объектное хранилище, куда физически падают parquet-файлы | Открытый исходный код, S3-совместимый API, работает локально в Docker без лицензии. |
| PostgreSQL | БД, где Lakekeeper хранит метаданные каталога | Надёжная реляционная БД, поддерживается Lakekeeper из-под коробки. |
| Lakekeeper | Iceberg REST Catalog — каталог метаданных таблиц | Реализует открытую спецификацию Iceberg REST Catalog, без привязки к облаку; метаданные лежат в Postgres, данные лежат в MinIO. |
| Trino | SQL-движок: берет в Lakekeeper метаданные, читает и пишет их в MinIO | Быстрый интерактивный SQL-движок с нативным коннектором Iceberg, поддержкой TPC-H и REST-каталогов. |
| Metabase | BI-инструмент поверх Bronze | Простой запуск в Docker, веб-интерфейс без настройки, есть драйвер Starburst/Trino. |

## Порты 

MinIO 9000/9001
Postgres 5433 (5432 занят моим PostgreSQL)
Lakekeeper 8181
Trino 8080
Metabase 3000

### Скрипты, которыми поднимал стек

```bash
docker run -d --name lakehouse-minio -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=minioadmin -e MINIO_ROOT_PASSWORD=minioadmin \
  -v minio-data:/data ghcr.io/coollabsio/minio:latest server /data --console-address ":9001"

docker run -d --name lakehouse-pg -e POSTGRES_PASSWORD=postgres -p 5433:5432 \
  -v pg-data:/var/lib/postgresql/data postgres:17

docker run --rm -e 'LAKEKEEPER__PG_ENCRYPTION_KEY=This-is-NOT-Secure!' \
  -e 'LAKEKEEPER__PG_DATABASE_URL_READ=postgresql://postgres:postgres@host.docker.internal:5433/postgres' \
  -e 'LAKEKEEPER__PG_DATABASE_URL_WRITE=postgresql://postgres:postgres@host.docker.internal:5433/postgres' \
  quay.io/lakekeeper/catalog:latest-main migrate

docker run -d --name lakekeeper -p 8181:8181 ... quay.io/lakekeeper/catalog:latest-main serve

docker run -d --name trino -p 8080:8080 \
  -v "${PWD}\catalog:/etc/trino/catalog" trinodb/trino:476

docker run -d --name metabase -p 3000:3000 \
  -v "${PWD}\metabase\plugins:/app/plugins" metabase/metabase:latest
